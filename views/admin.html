Kelola Tipe Sensor

Tipe sensor menentukan parameter yang dipantau (mis. Suhu Air, COD, Suhu Ruang). Untuk sensor bersumber Real, konfigurasi Modbus diatur lewat tombol "Tambah Sensor" — pilih Input Manual atau Auto Detect di dalam form. Sensor simulasi dibangkitkan otomatis dan dapat dipilih untuk tampilan dashboard tiap user.
Deteksi Lonjakan Data
Nilai dianggap lonjakan jika selisih dari bacaan sebelumnya melebihi max(abs_min, bacaan_sebelumnya × rasio). Data lonjakan tetap tersimpan di riwayat, namun tidak dihitung ke rata-rata. Contoh: normal 100 mg/L → lonjakan ke 5 atau 900 otomatis dicoret dari rata-rata.
